# Technical references

The data is generated locally and does not come from these sources. These official references document the tools and file formats used.

| Topic | Official reference |
|---|---|
| Power BI source-controlled projects | [Power BI Desktop projects](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-overview) |
| PBIR folder layout and schemas | [Power BI project report folder](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-report) |
| Semantic model definition formats | [Power BI project semantic model folder](https://learn.microsoft.com/en-us/power-bi/developer/projects/projects-dataset) |
| CSV imports in Power Query | [Csv.Document](https://learn.microsoft.com/en-us/powerquery-m/csv-document) |
| VBA CSV parsing | [Workbooks.OpenText](https://learn.microsoft.com/en-us/office/vba/api/excel.workbooks.opentext) |
| VBA PDF reporting | [Worksheet.ExportAsFixedFormat](https://learn.microsoft.com/en-us/office/vba/api/excel.worksheet.exportasfixedformat) |
| Publishing a local repository | [Adding locally hosted code to GitHub](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github) |

Power BI JSON files declare their Microsoft schema versions. Schema conformance is a file-structure check and does not replace refresh and visual testing in Desktop.
