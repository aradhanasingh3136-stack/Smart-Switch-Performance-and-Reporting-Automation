How this interactive demo runs

Python validates synthetic events, removes exact duplicates and builds a SQLite warehouse. This page loads its exported data and recalculates each selection in your browser. GitHub Actions rebuilds, tests and publishes the report.

P95 is calculated from successful command values. Heartbeat rates use expected counts. Energy is modeled from load ratings and runtime, not measured electricity savings. This is a JavaScript web dashboard; the repository also contains a separate native Power BI project.
